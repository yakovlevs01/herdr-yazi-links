# Установка на компьютер

[English](install.md)

В каталоге этого репозитория запустите:

```sh
./install.sh
```

На новом компьютере, где уже есть Git:

```sh
git clone https://github.com/yakovlevs01/herdr-yazi-links.git ~/pets/herdr-yazi-links
cd ~/pets/herdr-yazi-links
./install.sh
```

Скрипт устанавливает Herdr с патчем путей, плагин открытия файлов в Yazi, Ctrl+G и строку прогресса, локальный ripdrag, зависимости скачивания по SSH и команду `herdr-yazi`. После установки откройте новый терминал и заново откройте Yazi. Агент и ручное редактирование настроек не нужны. Для недостающих системных пакетов скрипт может запросить пароль sudo. Запускайте его от обычного пользователя.

Готовые сборки поддерживают Linux x86_64 и macOS Apple Silicon. В Linux скрипт работает с apt, dnf и pacman. На macOS использует Homebrew и при необходимости устанавливает его. Если ripdrag отсутствует, скрипт устанавливает библиотеки разработки GTK4 и собирает ripdrag через Cargo. Это может занять несколько минут. Для получения файлов в ripdrag нужен графический рабочий стол.

Запустите этот же скрипт по одному разу на каждой участвующей машине. На машине, которая только отправляет файлы по SSH, можно пропустить локальный GUI и получателя:

```sh
./install.sh --sender-only
```

Подключение с принимающего компьютера:

```sh
herdr-yazi --remote my-mac-m1 --remote-keybindings server
```

SSH-псевдонимы и доступ к хостам берутся из ваших настроек SSH. Скрипт не создаёт ключи и не меняет доверие к серверам. Если клонировать репозиторий в другой каталог, установщик создаст ссылку `~/pets/herdr-yazi-links` для удалённого запуска. Если этот путь занят другой копией репозитория, он остановится с объяснением конфликта.

## Что меняет скрипт

- Загружает в `.build/bin/herdr` закреплённую сборку с патчем из `install-assets.json`, сверяя SHA256. Она уже содержит патч обычных путей. Для прогресса дополнительных патчей бинарников нет.
- Использует Yazi из PATH, если это версия от 26.8.15 до конца серии 26.x. Иначе загружает проверенную по SHA256 версию 26.9.1 в `.build/yazi`. Если старый системный Yazi расположен раньше в PATH, файловая панель Herdr использует новую копию. Приоритет PATH в вашей оболочке сохраняется.
- Устанавливает Paramiko для получателя в `.build/drag-venv`. Если ripdrag отсутствует, собирает его в `.build/ripdrag` и создаёт ссылку в `~/.local/bin`.
- Настраивает Ctrl+G и управляемый блок в `init.lua` Yazi. Учитывает `YAZI_CONFIG_HOME` и `XDG_CONFIG_HOME`, сохраняет резервные копии изменённых настроек.
- Создаёт `~/.local/bin/herdr-yazi` и добавляет `~/.local/bin` в конец PATH через настройки оболочки, если его там ещё нет. Существующий файл команды сохраняет в резервную копию.
- Регистрирует плагин Herdr. Установщик не запускает, не останавливает и не перезапускает серверы Herdr и не вызывает `herdr-yazi update`.

Не удаляйте каталог репозитория: команда и плагин ссылаются на него. После обновления репозитория скрипт можно запускать повторно. Рабочие сессии Herdr продолжают работать, скачанные файлы остаются в кэше.

## Проверка установки

```sh
./install.sh --check
# Для машины только с отправкой:
./install.sh --sender-only --check
```

Команда проверяет зависимости, контрольную сумму Herdr, содержимое плагина, привязку Ctrl+G и подключение прогресса. Файлы не меняет и GUI drag-and-drop не проверяет. Проверки передачи и управление кэшем описаны в [инструкции по удалённому drag](drag.ru.md).

Инструментам установки нужен Python 3.11+. Скрипт устанавливает его через системный менеджер пакетов при необходимости. Если репозиторий вашей ОС предоставляет только старый Python, он сообщит об этом ограничении. Для такой машины нужна версия ОС с Python 3.11+.

## Управление сервером рабочего стола

На Linux/systemd с zsh используй `./install.sh --managed-server`, чтобы общая
сессия `yazi-links` не наследовала SSH-окружение. При повторной установке режим
сохраняется. Для серверов без графической сессии и других оболочек остаётся
обычная установка. [Переход и обслуживание](server-management.ru.md).
