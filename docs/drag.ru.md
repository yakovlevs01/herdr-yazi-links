# Передача удалённых файлов в локальный ripdrag

[English](drag.md)

Подключайся с компьютера, на котором нужно перетаскивать файлы:

```sh
herdr-yazi --remote my-mac-m1 --remote-keybindings server
```

В удалённом Yazi выдели файлы или оставь один под курсором и нажми Ctrl+G. Локальный помощник скачает копии и откроет ripdrag на компьютере подключения. Ghostty и панель удалённого Yazi остаются на месте. Во время загрузки можно продолжать работать в Yazi.

## Установка

На сервере репозиторий должен лежать в `~/pets/herdr-yazi-links`, как для существующего удалённого запуска. Для отправки нужны Python 3.9+, Yazi 26.x и OpenSSH с SFTP. Устанавливать ripdrag и Paramiko на отправителе не нужно.

На каждом компьютере с Yazi установи привязку через Python 3.11+:

```sh
python3 scripts/install-drag.py
```

Установщик сохраняет резервную копию keymap и меняет только Ctrl+G. Остальные привязки сохраняются. Открой новый процесс Yazi, чтобы загрузить настройку; Herdr перезапускать не нужно. Если Python сервера старее, скопируй его `~/.config/yazi` во временный локальный каталог, выполни `python3 scripts/install-drag.py --config-dir TEMP --root /абсолютный/путь/репозитория/на/сервере`, затем верни созданные `keymap.toml` и `plugins/herdr-drag.yazi/main.lua` на сервер. Перед заменой сохрани там резервную копию.

На каждом компьютере-получателе установи ripdrag и выполни:

```sh
sh scripts/install-drag-receiver.sh
```

Скрипт ставит Paramiko в `.build/drag-venv`. Наличие этого окружения включает получателя при `herdr-yazi --remote`. Приоритет пользовательского PATH сохраняется. Системный OpenSSH использует твои host aliases, ключи, ProxyJump и known_hosts. Сначала проверь обычный SSH-вход и ключ сервера; фоновые соединения используют BatchMode. Получателя проверяли на Linux с графической сессией и ripdrag в PATH. macOS и Ubuntu могут отправлять без GTK и ripdrag. Для получения на них нужен работающий локальный ripdrag; этот режим там не проверяли.

В обычном локальном Yazi сохраняется `shell -- ripdrag -x -a -n -b %s`. В локальной сессии Herdr помощник передаёт пути отдельными аргументами с теми же флагами ripdrag. `%s` в Yazi 26 означает выделенные файлы или файл под курсором. Устаревшая подстановка `$@` не используется.

## Получатель и переподключение

До подключения Herdr launcher запускает локального получателя. Его SSH-соединение запускает удалённый брокер с эксклюзивной OS-блокировкой для имени сессии Herdr. Второй получатель получает явную ошибку. Чтобы перенести получение на другой компьютер, закрой первый клиент. После обрыва связи подожди около 15 секунд до истечения heartbeat, затем подключись снова. Автоматического перехвата нет.

При каждом запросе Yazi определяет свою сессию по сокету Herdr. Адрес получателя не сохраняется в окружении Yazi, поэтому сервер и Yazi могут пережить локальное подключение. После первого удалённого подключения сессия сохраняет отметку в `~/.local/state/herdr-yazi-drag`. Если получатель отключён, Ctrl+G показывает ошибку вместо открытия ripdrag на сервере. Для полностью локальной работы используй отдельную сессию.

Выход клиента закрывает получателя, сервер Herdr продолжает работать. При отказе соединения получателя launcher закрывает только свой клиент и предлагает переподключиться. Запросы принадлежат случайному идентификатору подключения и не повторяются на другом компьютере. После переподключения незавершённые запросы нужно отправить заново. Готовые локальные копии сохраняются. На сессию допускается один получатель. Обычный Herdr и переходы через сохранённые машины получателя не регистрируют. На нужном компьютере используй `herdr-yazi --remote HOST`.

## Файлы, прогресс и ошибки

Брокер принимает JSON со списком абсолютных путей, без shell-команд. Пути файлов передаются строками SFTP и не попадают в команду shell. Лимиты одного запроса: 256 файлов и 64 КиБ JSON. У получателя могут ожидать восемь запросов. Переполнение очереди видно локально и в удалённом status.

Удалённая передача поддерживает только обычные файлы. Каталог, конечный симлинк, битая ссылка или специальный файл отклоняют всю группу. Симлинки промежуточных каталогов следуют обычным правилам сервера, в том числе `/tmp` на macOS. SFTP v3 не даёт атомарного открытия с запретом симлинков; функция рассчитана на доверенную SSH-учётную запись и файловую систему. Не меняй файлы во время загрузки. Проверки размера и времени изменения обнаруживают обычные изменения, но не создают snapshot файловой системы.

Группа загружается в отдельный приватный каталог `.partial-*` и становится `transfer-*` только после успеха всех файлов. Подкаталоги с индексами сохраняют одинаковые basename. Поддерживаются UTF-8, пробелы, кавычки, переводы строк и shell-символы. Имена вне UTF-8 отклоняются. Оригиналы не удаляются, обратной синхронизации нет. При обычной ошибке незавершённая группа удаляется. После аварии процесса или компьютера может остаться `.partial-*`; ripdrag такие файлы не получает.

Yazi показывает принятие запроса или ошибку соединения. Локальные desktop-уведомления показывают прогресс и ошибки при наличии `notify-send`. Прогресс в байтах и ошибки ripdrag записываются в `~/.cache/herdr-yazi-drag/receiver.log`. На сервере статус доступен так:

```sh
python3 ~/pets/herdr-yazi-links/drag.py status yazi-links
```

Другой кэш можно выбрать через `HERDR_DRAG_CACHE` на получателе. Копии остаются после выхода ripdrag, поскольку приложение может ещё читать их. Очистка ручная, после окончания чтения принимающими приложениями:

```sh
python3 scripts/drag-cache.py --older-than-days 7
```

Команда удаляет только завершённые группы старше заданного возраста, не трогая активные загрузки. После аварии оставшиеся `.partial-*` можно проверить и удалить вручную, когда получатели их больше не используют.

## Проверки и источники

`python3 -m unittest discover -s tests -v` проверяет запросы, маршрутизацию, переподключение, ошибки, завершение загрузки, очистку и установщик. `scripts/drag-smoke.py --remote HOST` проходит через настоящий launcher, новую удалённую сессию, клавиши Yazi и проверку байтов с подставным ripdrag, записывающим аргументы. Проверка запуска процесса не заменяет GUI-перетаскивание в другое приложение.

Разделение очереди и получателя близко к [yazi-ssh.yazi](https://github.com/affromero/yazi-ssh.yazi), который использует собственную SSH-обёртку. [drag.yazi](https://github.com/Joao-Queiroga/drag.yazi) решает локальное перетаскивание. Этот модуль запускает локальный [ripdrag](https://github.com/nik012003/ripdrag) и привязывает получателя к существующему удалённому запуску Herdr. Дополнительный патч бинарника не нужен.
