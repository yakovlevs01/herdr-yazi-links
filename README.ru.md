# Клик по файлам в Herdr

Ctrl+ЛКМ открывает Yazi справа от исходной панели с курсором на файле. `q` закрывает Yazi.

Есть два режима:

- Плагин обрабатывает готовые OSC 8 ссылки `file://`, если Herdr передаёт их обработчику.
- Патч Herdr дополнительно распознаёт обычный текст: `/абсолютный/путь`, `src/file.rs`, `README.md`. Одной установки плагина для этого недостаточно.

## Запуск

Из каталога этого репозитория:

```bash
./build.sh
./herdr-yazi
```

Для сборки нужны Rust 1.98.1, Zig 0.16.0, Python 3.11+, Git и Bash 4+. Путь к Zig можно передать через `ZIG=/путь/к/zig`. Сборка запускается отдельной сессией `yazi-links`, системный Herdr не заменяется. Бинарник и исходники Herdr хранятся в `.build/` вне Git.

Установка только плагина: `herdr plugin link /путь/к/herdr-yazi-links`.

Относительные пути разрешаются от рабочей папки процесса исходной панели. Проверяются только существующие файлы и каталоги, только при клике. Цвет текста не учитывается. Поддерживаются Unicode и переносы длинных строк. Пробелы допустимы в путях с `/`, заключённых в кавычки. Суффиксы `:строка:колонка` не поддерживаются.

Если автор подразумевал другой проект, совпадающее имя в текущей папке может привести к открытию другого файла. Содержимое ссылки не выполняется как команда оболочки.

## Версии и обновления

Плагин, тесты, патч и скрипт сборки версионируются вместе. Версия плагина находится в `herdr-plugin.toml`, изменения в `CHANGELOG.md`. Фиксированная ревизия Herdr и версии инструментов находятся в `patches/upstream.toml`.

Переход на новую версию Herdr требует проверки патча, тестов и Ctrl+клика в отдельной сессии. Сбой применения патча или сборки оставляет прежний бинарник. Замена готового бинарника атомарная; работающие серверы продолжают использовать прежнюю версию до отдельного перезапуска.

Проверки плагина: `python3 -m unittest discover -s tests -v`. Локально проверена Linux-сборка. Архитектура допускает работу на сервере через `--remote`, но удалённая работа пока не проверена.

## Публикация

Нужны публичный GitHub-репозиторий, манифест `herdr-plugin.toml` на основной ветке и тема `herdr-plugin`. Каталог индексирует такие проекты автоматически. Это community-плагин, а не официальное одобрение Herdr. Форки каталогу не подходят, поэтому плагин имеет собственный репозиторий, а модификация Herdr хранится небольшим патчем.
