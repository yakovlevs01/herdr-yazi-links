# herdr-yazi-links

Ctrl+клик по файловой гиперссылке в Herdr открывает Yazi справа от исходной панели и выделяет файл. Нажми `q`, чтобы закрыть Yazi.

[English](README.md) · [Установка плагина](docs/plugin.ru.md) · [Herdr с дополнительным патчем](docs/patched-herdr.ru.md)

## Выбери нужный режим

| Режим | По чему можно кликнуть | Что установить |
|---|---|---|
| Плагин в обычном Herdr | Терминальная гиперссылка OSC 8 с адресом `file:///абсолютный/путь` | Плагин |
| Плагин и дополнительный патч Herdr | Такие же ссылки и существующие пути обычным текстом, например `README.md`, `src/main.rs`, `/home/user/report.txt` | Плагин и сборку Herdr с патчем |

Манифест в корне репозитория устанавливает плагин. Установка не собирает, не скачивает и не заменяет Herdr. Патч и инструменты сборки лежат рядом для тех, кто хочет кликать по обычным путям в сообщениях агентов и выводе команд.

## Установка плагина

В PATH сервера Herdr должны быть Python 3 и Yazi:

```sh
herdr plugin install yakovlevs01/herdr-yazi-links
```

Для локальной копии репозитория:

```sh
herdr plugin link /абсолютный/путь/к/herdr-yazi-links
```

В [отдельном README плагина](docs/plugin.ru.md) описаны формат ссылок, демонстрация и диагностика. Фрагмент Markdown в обратных кавычках, например `README.md`, остаётся обычным текстом и требует патча. Markdown-ссылка работает, только если приложение преобразует её в терминальную гиперссылку.

## Совместимость и проверки

Работу одного плагина проверяли на Linux с обычным Herdr 0.9.0. Патч рассчитан на точную ревизию из [patches/upstream.toml](patches/upstream.toml). Работу на macOS, через `--remote` и преобразование Markdown конкретными приложениями агентов пока не проверяли. Минимальная версия Herdr в манифесте не гарантирует совместимости со всеми последующими версиями.

Запускай команды из репозитория:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/smoke.py --herdr /usr/bin/herdr
python3 scripts/smoke.py --herdr .build/bin/herdr --expect-paths
```

Smoke-проверки проходят через терминальное событие клика в отдельной тестовой сессии, без агента. Они не заменяют визуальную проверку с твоим терминалом и настоящим Yazi. Для ручной проверки запусти внутри Herdr `python3 scripts/demo.py` и кликни по примерам с Ctrl.

Обновление `/usr/bin/herdr` не меняет нашу сборку `.build/bin/herdr`. Команда `herdr-yazi` продолжит запускать закреплённую сборку. Чтобы получить новые функции и исправления из апстрима, её нужно явно пересобрать. См. [порядок обновления](docs/patched-herdr.ru.md).

## Публикация и версии

Репозиторий можно публиковать как community-плагин. Для каталога нужны публичный репозиторий GitHub, `herdr-plugin.toml` в корне основной ветки и тема `herdr-plugin`. Каталог автоматически индексирует подходящие репозитории. Наличие в каталоге не означает проверку или одобрение разработчиками Herdr. Форки исключены. См. [правила каталога Herdr](https://herdr.dev/docs/marketplace/).

Перед выпуском запусти тесты, обнови версию в манифесте и [CHANGELOG.md](CHANGELOG.md), затем создай соответствующий тег `vMAJOR.MINOR.PATCH`. Описывай совместимость плагина отдельно от ревизии, на которую рассчитан патч. Исходники Herdr, кэши и бинарники не коммитим; `.build/` исключён из Git.
